- all_sums and root's manual summing loop are removed.
- MPI_Reduce(&local_sum, &total_sum, 1, MPI_LONG_LONG, MPI_SUM, 0, MPI_COMM_WORLD)

- total_sum is only valid on root, so only root prints it.
