Exercise 3: Send/Recv replaced with Gather (sum_gather.c)
Run on: Debian Linux container (Docker), Open MPI 5.0.7, gcc 14.2, 8 cpus.

Changes from Exercise 2:
- Root allocates all_sums with one long long per process.
- The whole Send/Recv block is replaced by one call:
  MPI_Gather(&local_sum, 1, MPI_LONG_LONG, all_sums, 1, MPI_LONG_LONG, 0, MPI_COMM_WORLD)
- Root loops over all_sums to add them up (Gather only collects; it does not add).
